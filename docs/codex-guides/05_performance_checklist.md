# Performance Checklist

Follow these rules to keep a cinematic website fast.

## Media Limits

Hero video: 6--10MB\
Section images: 200--400KB\
Icons: SVG\
Thumbnails: \<100KB

## Key Techniques

1.  Lazy loading
2.  Compressed media
3.  GPU-friendly animations (transform, opacity)
4.  Minimal JavaScript
5.  CDN delivery

## Recommended Tools

Video compression: - HandBrake - FFmpeg

Image optimization: - Squoosh - ImageOptim

CDN: - Cloudflare

## Goal

Initial page load under **1.5 seconds**.
